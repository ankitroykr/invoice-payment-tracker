# Invoice and Payment Tracker

A personal learning project to build a full-stack website for freelancers to create invoices, record payments, and track outstanding balances.

I am developing the application incrementally, using small features to strengthen my understanding of application design, database development, testing, security, and cloud deployment.

## Project status

The repository has been initialised with an MIT licence and Git ignore rules. Application development is the next step.

The first milestone is to create an ASP.NET Core API that runs locally and exposes an endpoint confirming that the application is responding.

## Planned technology stack

- The frontend will use Angular and TypeScript.
- The backend will use C# and ASP.NET Core.
- Data will be stored in SQL Server using Entity Framework Core.
- Automated tests will cover business rules and application behaviour.
- GitHub Actions will support continuous integration and deployment.
- Azure will host the application in a later phase.

## Roadmap

- [ ] Create and run the initial API.
- [ ] Add endpoints to create and list invoices.
- [ ] Persist invoices in a database.
- [ ] Display and create invoices through an Angular website.
- [ ] Add payment tracking and outstanding-balance summaries.
- [ ] Introduce authentication and access controls.
- [ ] Extend automated testing and deploy to Azure.
- [ ] Explore background processing, reminders, and monitoring.

Each milestone will include relevant documentation and testing as the application grows.
